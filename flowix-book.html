Todo lo que necesitás saber sobre el software Flowix Book.

Flowix Book es la plataforma de software de turnos y agendamiento online (con bot de WhatsApp y cobro de señas). El Pack Flowix Salud & Citas incluye el software Flowix Book MÁS el diseño de un Sitio Web Corporativo completo y 2 Placas Smart NFC físicas para recepción y captación de reseñas de Google.

Sí. Flowix Book se puede integrar en cualquier sitio web existente (HTML, WordPress, Webflow, Shopify) mediante un botón flotante, un iframe embebido o como un link directo en tu biografía de Instagram y WhatsApp Business.

Podés definir si un servicio requiere seña previa (ej. $3.000 o el 50%) o si es de reserva libre. Al seleccionar el horario, el sistema abre la pasarela segura de Mercado Pago y solo confirma el turno cuando el pago fue exitoso.

En el recordatorio de WhatsApp, el paciente recibe los botones de "Confirmar" o "Reprogramar". Si reprograma, se abre el selector de nuevos horarios y el turno anterior se libera automáticamente para otros pacientes.

No hay límites. Podés recibir turnos ilimitados sin comisiones adicionales por volumen de pacientes ni cobros por consulta realizada.
